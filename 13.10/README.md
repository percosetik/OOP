# Проектирование предметной области ВКР (ООП)

## 1. Тема ВКР
**«Разработка информационной системы учёта заявок службы технической поддержки»**  
**Направление:** Информатика и вычислительная техника

---

## 2. Описание предметной области
Служба технической поддержки принимает и обрабатывает обращения сотрудников и пользователей информационной инфраструктуры предприятия. 

Для начального этапа проектирования выделены две ключевые базовые сущности:
1. **Пользователь (`User`)** — автор обращения в систему.
2. **Заявка (`Ticket`)** — обращение с информацией о возникшей проблеме, приоритете и текущем этапе обработки.

### Жизненный цикл заявки
Каждая заявка проходит через последовательность состояний:
$$\text{Новая} \longrightarrow \text{В работе} \longrightarrow \text{Решена} \longrightarrow \text{Закрыта}$$

---

## 3. Спроектированные классы

### Класс `User`
Представляет данные пользователя службы поддержки.
* **Поля (`private`):**
  * `id` (`int`) — уникальный идентификатор пользователя;
  * `name` (`std::string`) — имя / ФИО пользователя;
  * `email` (`std::string`) — контактный адрес электронной почты.
* **Методы (`public`):**
  * Конструктор инициализации;
  * Геттеры: `getId()`, `getName()`, `getEmail()`;
  * Метод `printInfo()` для форматированного вывода данных пользователя.

### Класс `Ticket`
Описывает обращение в службу поддержки.
* **Поля (`private`):**
  * `id` (`int`) — уникальный идентификатор заявки;
  * `title` (`std::string`) — краткая тема / заголовок проблемы;
  * `description` (`std::string`) — подробное описание проблемы;
  * `status` (`std::string`) — статус обработки (по умолчанию: `«Новая»`).
* **Методы (`public`):**
  * Конструктор инициализации;
  * Геттеры: `getId()`, `getTitle()`, `getDescription()`, `getStatus()`;
  * Сеттер: `setStatus(std::string newStatus)` — изменение текущего этапа жизненного цикла;
  * Метод `printInfo()` для вывода карточки заявки.
